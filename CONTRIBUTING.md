# Contributing a skill

1. Read [spec/v0.1.md](spec/v0.1.md).
2. Copy `skills/godaddy-renew-domain` as a template into `skills/<your-skill-name>/`.
3. Fill in `SKILL.md`, `browser.yaml` and `check.yaml`. No code files, no passwords, keys or personal data.
4. Open a pull request. Automatic checks and a sandbox run follow; the result is posted on your pull request.

By submitting you agree your skill is published under the Apache-2.0 license.
Never include a site whose terms forbid automation.
