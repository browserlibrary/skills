# BrowserLibrary skills

Verified browser skills for AI agents. Open format, open skills, verified by real runs.

- **Open format:** every skill is a folder with a standard `SKILL.md` (works in Claude Code, OpenClaw and other agents that read SKILL.md) plus `browser.yaml` and `check.yaml`. See [spec/v0.1.md](spec/v0.1.md).
- **Instructions only:** no skill ships code that runs on your machine. Sign-ins come from your own vault; paying, sending or deleting always stops and asks first.
- **Verified by real runs:** BrowserLibrary runs every listed skill in a sandbox and shows its live success rate.

Status: v0.1 draft. Submissions open soon at [browserlibrary.com](https://browserlibrary.com).
